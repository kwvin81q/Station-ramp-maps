# Ramp & Airport Maps

Standalone static site. Open index.html locally, or publish the root of this repository through GitHub Pages. No build step or API key is required.

The initial directory contains the eight major U.S. FedEx facilities from the FY2026 annual report. The app links to public source documents. Only Memphis is tagged as a verified ramp spot diagram in this initial directory. The FAA links open the station's procedure search, where the airport diagram can be selected. Source documents may be dated.

Add station entries in stations.js. Each entry contains IATA code, ICAO code, city, map type, publisher/document description, and source URL.
